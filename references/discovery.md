# Product discovery

For new capabilities, improvements, and validated experiments. A defect —
even one fixed with a feature — belongs to support.

Standalone-only: with an external workflow owner, its discovery record and PO
approval replace this gate — consume that record, never rerun discovery.

## Discovery gate

No specification without a discovery record naming: user/operator problem,
evidence, affected audience, constraints, hypothesis, expected value, and a
MEASURABLE success signal. A solution proposal alone is not a discovery;
unmeasurable "success" is a discovery gap, not an implementation order.

## Decision rights

- Product owner approves problem, scope, success criteria.
- Engineering owns the technical plan and implementation evidence.
- Design, security, data, and operations reviewers join when their boundaries
  are touched.

## Outcome

Close with an outcome record: success signal measured, value assessment,
learnings. Discovery → Specify → Plan → Preflight → Execute → Verify →
Release → Observe → Learn → Close.
