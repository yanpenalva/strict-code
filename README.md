# strict-code

Complete code writing and review standards (PHP/Laravel,
TypeScript/JavaScript/Vue): style, architecture, quality gates,
conventions, security, testing, process, and review checklist. All contents
in en-US.

- `SKILL.md` — core rules, guides, and verification.
- `references/style.md` — style (KISS/YAGNI, no-else, interpolation, typing, naming).
- `references/patterns.md` — layers, FSM, authorization, queries, exceptions, compatibility.
- `references/quality-gates.md` — strict ceilings, counting rules, enforcement, Sonar, hotspots.
- `references/conventions.md` — commits, hooks, toolchain, modern PHP, migrations.
- `references/security.md` — prohibitions, logs, auth, tokens, auditing.
- `references/testing.md` — layers, anatomy, conventions, completion record.
- `references/workflow.md` — task order, scope, Git, documentation.
- `references/review-checklist.md` — mandatory review checklist with severities.
