# code-standards-skill

Skill de padrões de escrita e revisão de código: estilo, limites, segurança,
testes e processo.

- `SKILL.md` — regras e quando usar.
- `references/style.md` — guia de estilo (KISS/YAGNI, sem-else, interpolação, tipagem, nomenclatura, limites).
- `references/security.md` — guia de segurança.
- `references/workflow.md` — guia de testes e processo.
