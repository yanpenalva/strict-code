# code-standards-skill

Guia completo de padrões de escrita e revisão de código (PHP/Laravel,
TypeScript/JavaScript/Vue): estilo, arquitetura, gates de qualidade,
convenções, segurança, testes, processo e checklist de revisão.

- `SKILL.md` — regras nucleares, guias e verificação.
- `references/style.md` — estilo (KISS/YAGNI, sem-else, interpolação, tipagem, nomenclatura, limites).
- `references/patterns.md` — camadas, FSM, autorização, queries, exceções, compatibilidade.
- `references/quality-gates.md` — tetos estruturais, Sonar, supressões, hotspots.
- `references/conventions.md` — commits, hooks, toolchain, PHP moderno, migrations.
- `references/security.md` — proibições, logs, auth, tokens, auditoria.
- `references/testing.md` — camadas, anatomia, convenções, registro de conclusão.
- `references/workflow.md` — ordem do trabalho, escopo, Git, documentação.
- `references/review-checklist.md` — checklist obrigatório de revisão.
