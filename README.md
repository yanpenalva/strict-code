TypeScript/JavaScript/Vue). All contents in en-US.

- `references/style.md` — style (KISS/YAGNI, no-else, interpolation, typing, naming).
- `references/solid.md` — SOLID with worked examples.
- `references/modern-php.md` — modern PHP feature catalog.
- `references/laravel.md` — Laravel specifics.
- `references/anti-patterns.md` — smell → rule → fix catalog.
- `references/patterns.md` — layers, FSM, authorization, queries, exceptions, compatibility.
- `references/quality-gates.md` — strict ceilings, counting rules, enforcement, Sonar, hotspots.
- `references/conventions.md` — commits, hooks, toolchain, migrations.
- `references/security.md` — prohibitions, logs, auth, tokens, auditing.
- `references/api-contracts.md` — envelope, status codes, masking, uploads.
- `references/testing.md` — layers, anatomy, conventions, completion record.
- `references/frontend.md` — Vue 3 + TypeScript specifics.
- `references/intake.md` — intake, classification, routing, escalation.
- `references/delivery.md` — stages, artifacts, waves, handoffs, closing criteria.
- `references/workflow.md` — task order, scope, Git, documentation.
- `references/review-checklist.md` — mandatory review checklist with severities.
- `references/artifact-templates.md` — spec/review/progress/manifest shapes.
- `references/agent-comms.md` — dense communication + prompt/handoff shapes.
- `references/architecture-decisions.md` — ADR practice + stack checklist.
- `references/module-docs.md` — domain documentation standard.
